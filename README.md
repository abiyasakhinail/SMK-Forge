# SMK-Forge

### Platform Pameran Proyek Mahasiswa

---

## Deskripsi

SMK-Forge merupakan platform pameran proyek mahasiswa yang dirancang untuk menampilkan berbagai karya, inovasi, dan hasil pembelajaran mahasiswa kepada masyarakat secara online.

---

## Tujuan

- Menjadi wadah publikasi karya mahasiswa.
- Memudahkan masyarakat melihat dan mengakses proyek mahasiswa.
- Meningkatkan apresiasi terhadap kreativitas dan inovasi mahasiswa.
- Membantu mahasiswa membangun portofolio digital.

---

## Fitur

- Registrasi dan Login
- Dashboard Pengguna
- Upload Proyek
- Edit Proyek
- Hapus Proyek
- Galeri Proyek
- Logout
